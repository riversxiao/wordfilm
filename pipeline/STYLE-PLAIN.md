# 歌词写法：给零基础的普通人（第二季起）

观众是没学过金融的普通人。听完一遍能复述出双方各自的道理，就算成功。

- **不用术语，用生活场景**：不说"久期""β""信用利差"，说"房贷""工资""奶茶""菜市场""压岁钱"。确实要提一个词（比如"复利"），全片最多一两个，并且下一句马上用大白话解释。
- **数字要小、要整、要能心算**：一万块、每月一千、翻一倍、少一半。不出现公式、希腊字母、小数点后两位。
- **一句只讲一件事**，每句不超过 16 个字左右，读出来顺口。
- **双方都要有道理**：不丑化任何一方，最后给一个普通人能直接照做的建议（比如"先留半年生活费"）。
- **解释卡也说人话**：卡片用"对比柱、计数器、天平、链条"画出生活里的例子，不放公式卡。
- **故事贴近日常**：年终奖、租房合同到期、爸妈催买房、发工资那天、双十一。
